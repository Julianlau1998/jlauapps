How to run Python on iPhone and iPad (offline)

iOS doesn't come with Python, and you can't install it the way you would on a computer. Instead, you use an app that brings its own Python interpreter – then you can write and run real Python 3 code on an iPhone or iPad, on the train, in class or anywhere without Wi-Fi.

This guide shows you how that works, walks through a first script with input(), reads data from a file and draws a chart with numpy and matplotlib.

How Python runs on an iPhone

Apps can bring their own Python interpreter. When it runs on the device itself, your code never needs a server, and you don't need a connection to run it.

Python Editor works this way: Python 3 runs right in the app, also offline, without an account. print() and input() work in a console like a terminal, and errors come with their line number and a hint in plain words about what went wrong.

Your first script with input()

Interactive programs are the best way to start. This one asks for your name and a few scores and prints the average. Leave the input empty to finish.

name = input("Your name: ")
scores = []

while True:
    entry = input("Score (leave empty to finish): ")
    if entry == "":
        break
    scores.append(float(entry))

if scores:
    average = sum(scores) / len(scores)
    print(f"{name}, your average is {average:.1f}")
else:
    print("No scores entered.")
  • input() always returns text, so float(entry) turns it into a number.
  • The while True loop runs until break is reached.
  • The f-string with :.1f prints one decimal place.

Reading files from your project

Real programs often work with data. Put a file called data.csv next to your script, with a header line name,points followed by one row per person, such as Ada,42. The csv module from the standard library reads it into dictionaries.

import csv

with open("data.csv", newline="") as f:
    rows = list(csv.DictReader(f))

for row in rows:
    print(row["name"], row["points"])

best = max(rows, key=lambda row: int(row["points"]))
print("Top score:", best["name"])
  • In Python Editor, every folder is a project with a file list and tabs.
  • Your program reads files like data.csv from its own folder and can import your own modules.
  • You can open folders from the Files app and iCloud Drive right where they are.

Which libraries are available

The whole standard library is there: math, random, csv, json, datetime, collections, re and the rest. Beyond that, Python Editor includes numpy and matplotlib, so you can calculate with arrays and draw charts offline. Other packages like pandas, scipy or sympy download the first time you import them – that one time you need an internet connection.

Not every package from PyPI works on a phone. Libraries that need a desktop window, access to hardware or a running server are usually not an option.

numpy and matplotlib on iPad

This script computes sine and cosine for 200 points and plots both curves. In Python Editor, the chart appears right in the console. If you want to explain each step next to its chart, try a Jupyter notebook on iPad.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
plt.plot(x, np.sin(x), label="sin(x)")
plt.plot(x, np.cos(x), label="cos(x)")
plt.legend()
plt.title("Sine and cosine")
plt.show()

Understanding error messages

When something goes wrong, Python prints a traceback. Read it from the bottom: the last line names the error type and what happened, the lines above it show where. The ones you'll see most as a beginner:

ErrorUsually means
SyntaxErrorA missing colon, bracket or quote
IndentationErrorLines inside a block aren't indented consistently
NameErrorA typo in a name, or a variable used before it was set
ValueErrorFor example float("abc") – text that isn't a number
FileNotFoundErrorThe file isn't in the folder you think it is

Tips for typing Python on a touch screen

Indentation is part of Python's syntax, which makes a good editor important on a phone. Python Editor indents automatically after a colon, closes brackets and quotes, and has a bar above the keyboard with Tab, symbols and building blocks like if, for, def and class. With a hardware keyboard on iPad, keyboard shortcuts work too.

Frequently asked questions

Can I run Python on iPhone without internet?

Yes. Python Editor runs Python 3 on the device itself, including the standard library, numpy and matplotlib. Only extra packages like pandas need a connection once, when they download on first import.

Can I install Python on iPhone?

Not as a system-wide program like on a computer – iOS doesn't allow that. Apps bring their own interpreter instead. Python Editor includes Python 3 with its standard library, numpy and matplotlib.

Can I use pandas on iPad?

In Python Editor, pandas downloads the first time your program imports it. After that, you can use it like on a computer.

Do I need pip to install packages?

No. In Python Editor, packages like pandas, scipy or sympy download automatically the first time your program imports them. Not every package from PyPI is available, especially ones that need a desktop window or hardware access.

Does input() work on iPhone?

Yes. In Python Editor, input() asks for your answer in the console, just like in a terminal on a computer.

Is Python Editor free?

Yes. Running Python, packages, notebooks, the examples and everything for learning are free. Pro adds comfort features such as an AI assistant, iCloud sync and no ads, as a monthly or yearly subscription.
