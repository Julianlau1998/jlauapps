LaTeX math cheat sheet: fractions, roots, integrals, Greek letters

This cheat sheet collects the LaTeX math commands you need most often, grouped by topic. Every command goes inside math mode, so wrap it in $…$ for inline math or \[…\] for a displayed formula.

Most commands are part of core LaTeX. Some come from the amsmath or amssymb packages; they are marked in the tables. In a full LaTeX document, load them in the preamble with \usepackage{amsmath} and \usepackage{amssymb}. Many formula editors and web renderers include these commands out of the box.

Greek letters

Lowercase Greek letters are written as their name with a backslash. For uppercase letters, capitalize the first letter of the command – but only where the uppercase letter looks different from a Latin one. Uppercase alpha, beta and the others are just the Latin letters A, B and so on; there is no \Alpha in standard LaTeX. There is no \omicron either; use a plain o.

Variant forms: \varepsilon, \vartheta, \varphi, \varrho, \varsigma and \varpi. Many people prefer \varepsilon and \varphi because they match handwriting.

Sums, integrals, limits and functions

Limits of sums, products and integrals are written as subscript and superscript. In display math they appear above and below the symbol, inline they move to the side. The small space \, before dx is a typographic convention that separates the differential from the integrand.

Brackets, dots and spacing

Plain parentheses keep their size. \left and \right make a pair of delimiters grow with the content between them; they must always come in pairs. If you only need one side, use a dot as an invisible partner: \left. … \right|. Matrices, aligned equations, systems and cases are covered in the LaTeX matrix guide.

Frequently asked questions

How do I write a fraction in LaTeX?

Use \frac{numerator}{denominator}, for example \frac{a}{b}. With amsmath, \dfrac{a}{b} forces a large fraction and \tfrac{a}{b} a small one.

How do I write a square root or an n-th root?

\sqrt{x} gives the square root; the optional argument in square brackets sets the degree, for example \sqrt[3]{x} for the cube root.

How do I write text inside a formula?

Use \text{…} from amsmath, for example x > 0 \text{ for all } x. Spaces inside \text are kept, so add them yourself at the start and end where needed.

How do I write the degree symbol in LaTeX?

In math mode, write ^\circ, for example $90^\circ$. In running text, current LaTeX versions also understand \textdegree.

How do I make parentheses grow with a fraction?

Write \left( … \right) around the content. The delimiters scale to the height of what is between them; both parts must always come as a pair.

Why does \mathbb{R} not work?

\mathbb is defined in the amssymb package (or amsfonts). Add \usepackage{amssymb} to the preamble of your document. Many formula editors load it automatically.
