Writing Markdown on iPhone and iPad

Markdown is a good fit for mobile writing. It is plain text, so any keyboard works, the files are tiny, and the same document opens on your phone, your tablet and your computer. What the iPhone lacks out of the box is a way to see Markdown formatted and a comfortable way to type the symbols.

This guide shows where .md files live on iOS and iPadOS, how to open them, how to write efficiently on a touch keyboard and how to share the finished result.

Markdown Editor and Reader

Where .md files live on iPhone and iPad

Markdown files are ordinary files, so they belong in the Files app – on the device, in iCloud Drive or in another cloud provider you have connected. The Files app can store and organize .md files, but it does not show their formatting. For that you need an app that renders Markdown.

Markdown Editor keeps your documents as plain .md files in the Files app under “On My iPhone › Markdown Editor”. Nothing is locked in a database: you can copy, back up or move the files like any others – the same reason plain-text notes outlast most note apps.

How to open a .md file on iPhone

If someone sends you a README or notes as a .md file, save it to Files first, for example from Mail or Messages. Then open it in a Markdown app. Markdown Editor opens Markdown and text files from iCloud Drive or other apps and edits them right where they are, so changes end up in the original file instead of a copy.

If you mostly read Markdown, you can set documents to open straight in the preview.

Typing Markdown on a touch keyboard

The symbols Markdown relies on – #, *, [ ] and | – sit on the second symbol layer of the iOS keyboard. Typing them one by one works, but it is slow. A formatting bar above the keyboard saves most of those trips.

Markdown Editor's bar inserts a heading, bold, italic, lists, checklists, links, code, quotes, tables and images with one tap. Lists continue by themselves when you press Return. On iPad with a keyboard, ⌘B, ⌘I and ⌘K make text bold, italic or a link. While you type, syntax highlighting marks headings, emphasis, code, links, lists and quotes, and the Markdown characters step back visually so your text stays in focus.

A small example to try (every piece of syntax is in the Markdown cheat sheet):

# Shopping list

## Weekend

- [ ] Coffee
- [x] Bread

**Note:** the market closes at *2 pm*.

Preview: check the formatted result

Markdown only pays off when you see the result. In Markdown Editor, a tap on the eye shows the document formatted, with tables, checklists, nested lists, code blocks and images. On iPad, the text and the live preview sit side by side, which is the most comfortable way to write longer pieces.

Keeping documents organized

Once you have more than a handful of notes, structure helps. Markdown Editor offers folders with their own color and icon, pinning, sorting by date, name or your own order via drag and drop, and a search that finds every word across all documents. Find and replace, a word count, reading time and printing are built in.

Sharing and exporting: PDF and HTML

The simplest way to share Markdown is the .md file itself – anyone with a Markdown app or a code editor can open it. For people who just want to read, a formatted document is friendlier.

Markdown Editor Pro exports documents as beautifully formatted PDF or HTML and syncs them between iPhone and iPad via iCloud. Pro is a monthly or yearly subscription and also includes eight designs, widgets, version history and an app lock with a private folder via Face ID.

Tips for writing on the go

  • Start each document with a # heading; many apps and sites use it as the title.
  • Leave a blank line between paragraphs, lists and tables.
  • Use task lists (- [ ] and - [x]) for to-dos; they render as checkboxes in GFM-compatible previews.
  • Keep images next to the document or use full URLs so links still work on other devices.
  • For long texts on iPad, an external keyboard and the side-by-side preview make a real difference.

Frequently asked questions

Can I open .md files on my iPhone without an app?

The Files app can store .md files, but it does not render Markdown formatting. To read or edit them comfortably, open them in a Markdown app.

Can I edit .md files that are stored in iCloud Drive?

Yes. Markdown Editor opens Markdown and text files from iCloud Drive or other apps and edits them right where they are, so your changes end up in the original file.

Is there a Markdown editor for iPad with a live preview?

Yes. Markdown Editor shows text and live preview side by side on iPad and supports the keyboard shortcuts ⌘B, ⌘I and ⌘K.

How do I convert Markdown to PDF on iPhone?

With Markdown Editor Pro, you can export a document as a formatted PDF or as HTML. The .md file itself stays unchanged in the Files app.

Can I sync Markdown notes between iPhone and iPad?

Yes, with Markdown Editor Pro your documents sync between iPhone and iPad via iCloud. Without Pro, you can keep .md files in iCloud Drive and open them in place on each device.
