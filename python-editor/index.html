Python Editor: Learn & Code

Run Python 3 Code Offline

Learn Python and try it out – right on your iPhone, iPad and Mac. Python Editor runs your code on the device, with no account and no internet needed. Made for school, college, coding classes and everyone just getting started.

Free · In-app purchases

Features

RUN PYTHON

  • Python 3 runs right in the app, also offline
  • print(), input() and a console like a terminal
  • Errors with their line number and a hint in plain words about what went wrong
  • numpy and matplotlib are built in; other packages like pandas, scipy or sympy download on first import

DRAWINGS AND CHARTS

Watch the turtle draw stars, spirals and houses with the turtle module, just like in computer science class. Charts from matplotlib show up right in the console.

JUPYTER NOTEBOOKS

Open and write .ipynb files: code cells you run one at a time, with text and output in between. The cells share their variables – just like in Jupyter.

20 EXAMPLES TO START FROM

Guess the number, rock paper scissors, prime numbers, a colorful spiral, grades from a CSV file, a quiz from JSON and more. Each example becomes a file of your own to run and change.

MADE FOR WRITING CODE

  • Syntax highlighting and line numbers
  • Suggestions as you type for Python, math, random, turtle, numpy and more
  • A bar above the keyboard with Tab, symbols and building blocks like if, for, def and class
  • Brackets and quotes close themselves, and lines indent after a colon
  • Find and replace, go to line and keyboard shortcuts

WHOLE PROJECTS

Every folder is a project with a file list, tabs and search. Your program imports its own modules and reads files like data.csv from its folder. Open folders from the Files app and iCloud Drive right where they are.

ALSO FOR MARKDOWN, JSON, CSV, YAML AND TOML

With highlighting and a preview for Markdown.

ON THE MAC TOO

With a menu bar, multiple windows and keyboard shortcuts.
