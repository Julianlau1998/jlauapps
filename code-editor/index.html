Code Editor: HTML, Python, JS

Websites & Scripts on the Go

Write HTML, CSS, JavaScript and Python on iPhone, iPad and Mac – and see what your code does right away. Code Editor opens in an instant, with no account and no internet needed. For websites, scripts, homework, coding classes and every quick fix on the go.

iPhoneiPadMacFree

Features

A CONSOLE BUILT IN

console.log, warnings and errors with their line number appear right below the preview. Tap an error to jump to its line. Try out JavaScript and Python in the prompt, with a history like a terminal.

MADE FOR TOUCH

  • Suggestions as you type for HTML, CSS, JavaScript and Python
  • A bar above the keyboard with Tab, symbols and building blocks for every language
  • Brackets, quotes and HTML tags close themselves
  • Find and replace, go to line, line wrapping on or off
  • Keyboard shortcuts for hardware keyboards

LIVE PREVIEW FOR WEB PAGES

Your HTML page shows up as you type – below the code on iPhone, next to it on iPad and Mac. CSS, JavaScript and images from the project load along, just like on a real web server. Full screen preview with one tap.

RUN YOUR CODE

  • JavaScript runs right on your device
  • Python 3 with its standard library, offline (Pro)
  • print(), input() and error messages in the console

20+ LANGUAGES

HTML, CSS, JavaScript, TypeScript, JSON, Markdown, Python, Swift, C, C++, Java, Kotlin, C#, Go, Rust, PHP, Ruby, SQL, YAML, XML and Shell – with syntax highlighting, line numbers and ⌘/ comments.

WHOLE PROJECTS

Every folder is a project: a file list, tabs, search across the project and go to file. Start with a ready-made website or an empty project, or open a folder from the Files app and iCloud Drive right where it is. A style sheet shows the page it styles, live.

REAL FILES

Everything is a plain file in the Files app. Edit files from other apps right where they are. Cards on the home screen show each file's first lines in color, with pins and sorting.

ON THE MAC TOO

With a menu bar, multiple windows and keyboard shortcuts – one subscription works on all your devices.

PRO

AI ASSISTANT (PRO)

Ask Claude, ChatGPT or Gemini right next to your code: “Give my page a dark mode”, “Why doesn't the button work?”. The assistant reads your project's files and proposes changes. You see every change highlighted and decide whether to apply it – earlier states stay in the version history. Works with your own API key from Anthropic, OpenAI or Google; conversations are kept per project.
