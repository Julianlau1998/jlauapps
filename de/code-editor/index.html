Code Editor: HTML, Python, JS

Websites & Skripte unterwegs

Schreib Code auf iPhone, iPad und Mac – und sieh sofort, was er macht. Code Editor öffnet in einem Augenblick, ohne Konto und ohne Internet. Für Webseiten, Skripte, Hausaufgaben, Programmierkurse und alles, was du unterwegs schnell ändern willst.

Gratis · In-App-Käufe

Funktionen

LIVE-VORSCHAU FÜR WEBSEITEN

Deine HTML-Seite erscheint schon beim Tippen – auf dem iPhone darunter, auf dem iPad und Mac daneben. CSS, JavaScript und Bilder aus dem Projekt werden mitgeladen, wie auf einem echten Webserver. Vollbild-Vorschau mit einem Tipp.

EINGEBAUTE KONSOLE

console.log, Warnungen und Fehler mit Zeilennummer erscheinen direkt unter der Vorschau. Tipp auf einen Fehler und du springst zur Zeile. In der Eingabe probierst du JavaScript und Python sofort aus, mit Verlauf wie im Terminal.

KI-ASSISTENT (PRO)

Frag Claude, ChatGPT oder Gemini direkt neben deinem Code: „Gib meiner Seite einen Dark Mode“, „Warum funktioniert der Button nicht?“. Der Assistent liest die Dateien deines Projekts und schlägt Änderungen vor. Du siehst jede Änderung farbig markiert und entscheidest selbst, ob du sie übernimmst – frühere Stände bleiben im Versionsverlauf. Funktioniert mit deinem eigenen API-Schlüssel von Anthropic, OpenAI oder Google; deine Unterhaltung wird pro Projekt gemerkt.

CODE AUSFÜHREN

  • JavaScript läuft direkt auf deinem Gerät
  • Python 3 mit Standardbibliothek, offline (Pro)
  • print(), input() und Fehlermeldungen in der Konsole

ÜBER 20 SPRACHEN

HTML, CSS, JavaScript, TypeScript, JSON, Markdown, Python, Swift, C, C++, Java, Kotlin, C#, Go, Rust, PHP, Ruby, SQL, YAML, XML und Shell – mit Syntax-Hervorhebung, Zeilennummern und Kommentaren per ⌘/.

GEMACHT FÜR TOUCH

  • Vorschläge beim Tippen für HTML, CSS, JavaScript und Python
  • Leiste über der Tastatur mit Tab, Sonderzeichen und Bausteinen für jede Sprache
  • Klammern, Anführungszeichen und HTML-Tags schließen sich selbst
  • Suchen und Ersetzen, Gehe zu Zeile, Zeilenumbruch an oder aus
  • Tastaturkurzbefehle für Hardware-Tastaturen

GANZE PROJEKTE

Jeder Ordner ist ein Projekt: Dateiliste, Tabs, Suchen im ganzen Projekt und Gehe zu Datei. Starte mit einer fertigen Website oder einem leeren Projekt, oder öffne einen Ordner aus der Dateien-App und iCloud Drive direkt dort, wo er liegt. Ein Stylesheet zeigt live die Seite, auf der es wirkt.

ECHTE DATEIEN

Alles sind normale Dateien in der Dateien-App. Dateien aus anderen Apps bearbeitest du direkt dort, wo sie liegen. Karten auf dem Startbildschirm zeigen den Anfang jeder Datei mit Farben, dazu Anheften und Sortieren.

AUCH AUF DEM MAC

Mit Menüleiste, mehreren Fenstern und Tastaturkurzbefehlen – ein Abo gilt auf allen deinen Geräten.
