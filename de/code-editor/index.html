Häufige Fragen

Braucht Code Editor ein Konto oder Internet?

Nein. Code Editor öffnet in einem Augenblick, ohne Konto und ohne Internet. JavaScript läuft direkt auf deinem Gerät.

Kann ich mit Code Editor Python offline auf dem iPhone ausführen?

Ja, mit Code Editor Pro: Python 3 mit Standardbibliothek läuft offline, mit print(), input() und Fehlermeldungen in der Konsole. JavaScript läuft auch ohne Pro direkt auf deinem Gerät.

Hat Code Editor eine Live-Vorschau für HTML?

Ja. Deine HTML-Seite erscheint schon beim Tippen – auf dem iPhone unter dem Code, auf iPad und Mac daneben –, und CSS, JavaScript und Bilder aus dem Projekt werden wie auf einem echten Webserver mitgeladen. Die eingebaute Konsole zeigt console.log, Warnungen und Fehler mit Zeilennummer.

Wie funktioniert der KI-Assistent in Code Editor?

Der KI-Assistent gehört zu Pro und arbeitet mit Claude, ChatGPT oder Gemini über deinen eigenen API-Schlüssel von Anthropic, OpenAI oder Google. Er liest die Dateien deines Projekts und schlägt Änderungen vor, die du farbig markiert siehst und selbst übernimmst oder verwirfst. Die Anfragen rechnet der jeweilige Anbieter über deinen Schlüssel ab.

Läuft Code Editor auf iPad und Mac?

Ja. Code Editor läuft auf iPhone, iPad und Mac, auf dem Mac mit Menüleiste, mehreren Fenstern und Tastaturkurzbefehlen. Ein Abo gilt auf allen deinen Geräten, und mit Pro synchronisierst du per iCloud.
