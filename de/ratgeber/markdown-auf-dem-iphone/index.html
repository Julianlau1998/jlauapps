Markdown auf dem iPhone und iPad schreiben

Markdown passt gut zum Schreiben unterwegs. Es ist reiner Text, jede Tastatur funktioniert, die Dateien sind winzig, und dasselbe Dokument öffnet sich auf Handy, Tablet und Rechner. Was dem iPhone von Haus aus fehlt, ist eine formatierte Ansicht und eine bequeme Möglichkeit, die Zeichen zu tippen.

Diese Anleitung zeigt, wo .md-Dateien unter iOS und iPadOS liegen, wie du sie öffnest, wie du auf der Bildschirmtastatur zügig schreibst und wie du das fertige Ergebnis teilst.

Wo .md-Dateien auf dem iPhone und iPad liegen

Markdown-Dateien sind ganz normale Dateien und gehören deshalb in die Dateien-App – auf das Gerät, in iCloud Drive oder zu einem anderen verbundenen Cloud-Anbieter. Die Dateien-App kann .md-Dateien speichern und ordnen, zeigt ihre Formatierung aber nicht an. Dafür brauchst du eine App, die Markdown darstellt.

Markdown Editor speichert deine Dokumente als normale .md-Dateien in der Dateien-App unter „Auf meinem iPhone › Markdown Editor“. Nichts steckt in einer Datenbank fest: Du kannst die Dateien kopieren, sichern oder verschieben wie alle anderen.

So öffnest du eine .md-Datei auf dem iPhone

Schickt dir jemand eine README oder Notizen als .md-Datei, sicherst du sie zuerst in der Dateien-App, zum Beispiel aus Mail oder Nachrichten. Danach öffnest du sie in einer Markdown-App. Markdown Editor öffnet Markdown- und Textdateien aus iCloud Drive oder anderen Apps und bearbeitet sie direkt dort, wo sie liegen – Änderungen landen also in der Originaldatei statt in einer Kopie.

Wenn du Markdown vor allem liest, kannst du einstellen, dass sich Dokumente direkt in der Vorschau öffnen.

Markdown auf der Bildschirmtastatur tippen

Die Zeichen, auf die Markdown setzt – #, *, [ ] und | –, liegen auf der zweiten Symbolebene der iOS-Tastatur. Einzeln tippen geht, ist aber langsam. Eine Formatierungsleiste über der Tastatur erspart dir die meisten dieser Umwege.

Die Leiste in Markdown Editor fügt Überschrift, Fett, Kursiv, Listen, Checklisten, Links, Code, Zitate, Tabellen und Bilder mit einem Tipp ein. Listen setzen sich bei Return von selbst fort. Auf dem iPad mit Tastatur machen ⌘B, ⌘I und ⌘K Text fett, kursiv oder zum Link. Beim Tippen hebt das Syntax-Highlighting Überschriften, Hervorhebungen, Code, Links, Listen und Zitate hervor, und die Markdown-Zeichen treten optisch zurück, damit dein Text im Vordergrund bleibt.

Ein kleines Beispiel zum Ausprobieren:

# Einkaufsliste

## Wochenende

- [ ] Kaffee
- [x] Brot

**Hinweis:** Der Markt schließt um *14 Uhr*.

Vorschau: das formatierte Ergebnis prüfen

Markdown lohnt sich erst, wenn du das Ergebnis siehst. In Markdown Editor zeigt ein Tipp aufs Auge das Dokument formatiert, mit Tabellen, Checklisten, verschachtelten Listen, Codeblöcken und Bildern. Auf dem iPad stehen Text und Live-Vorschau nebeneinander – so schreibst du längere Texte am bequemsten.

Dokumente ordnen

Sobald du mehr als eine Handvoll Notizen hast, hilft Struktur. Markdown Editor bietet Ordner mit eigener Farbe und eigenem Symbol, Anheften, Sortieren nach Datum, Name oder eigener Reihenfolge per Drag & Drop und eine Suche, die jedes Wort in allen Dokumenten findet. Suchen und Ersetzen, Wortzähler, Lesezeit und Drucken sind eingebaut.

Teilen und exportieren: PDF und HTML

Am einfachsten teilst du Markdown als .md-Datei – jeder mit einer Markdown-App oder einem Code-Editor kann sie öffnen. Für Menschen, die nur lesen wollen, ist ein formatiertes Dokument angenehmer.

Markdown Editor Pro exportiert Dokumente schön formatiert als PDF oder HTML und synchronisiert sie per iCloud zwischen iPhone und iPad. Pro gibt es als Monats- oder Jahresabo; dazu gehören auch acht Designs, Widgets, ein Versionsverlauf und eine App-Sperre mit privatem Ordner per Face ID.

Tipps fürs Schreiben unterwegs

  • Beginne jedes Dokument mit einer #-Überschrift; viele Apps und Websites nutzen sie als Titel.
  • Lass zwischen Absätzen, Listen und Tabellen eine Leerzeile.
  • Nimm Checklisten (- [ ] und - [x]) für To-dos; in GFM-kompatiblen Vorschauen erscheinen sie als Kästchen.
  • Leg Bilder neben das Dokument oder nutze vollständige URLs, damit Links auch auf anderen Geräten funktionieren.
  • Für lange Texte auf dem iPad machen eine externe Tastatur und die Vorschau daneben einen echten Unterschied.

Häufige Fragen

Kann ich .md-Dateien auf dem iPhone ohne App öffnen?

Die Dateien-App kann .md-Dateien speichern, stellt die Markdown-Formatierung aber nicht dar. Zum bequemen Lesen und Bearbeiten öffnest du sie in einer Markdown-App.

Gibt es einen Markdown-Editor fürs iPad mit Live-Vorschau?

Ja. Markdown Editor zeigt auf dem iPad Text und Live-Vorschau nebeneinander und unterstützt die Tastaturkürzel ⌘B, ⌘I und ⌘K.

Wie wandle ich Markdown auf dem iPhone in ein PDF um?

Mit Markdown Editor Pro exportierst du ein Dokument formatiert als PDF oder als HTML. Die .md-Datei selbst bleibt unverändert in der Dateien-App.
