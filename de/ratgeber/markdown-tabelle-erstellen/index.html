Tabelle in Markdown erstellen

Tabellen gehören weder zum ursprünglichen Markdown noch zu CommonMark. Sie stammen aus GitHub Flavored Markdown (GFM), und weil GitHub sie bekannt gemacht hat, unterstützt fast jeder moderne Markdown-Editor und Static-Site-Generator dieselbe Schreibweise mit senkrechten Strichen.

In dieser Anleitung geht es um den Grundaufbau, das Ausrichten von Spalten, Maskieren und Formatieren in Zellen und um die Grenzen, an die du früher oder später stößt.

Der Grundaufbau

Eine Markdown-Tabelle besteht aus drei Teilen: einer Kopfzeile, einer Trennzeile und beliebig vielen Zeilen mit Inhalt. Senkrechte Striche (|, auch „Pipes“ genannt) trennen die Zellen. Die Trennzeile besteht aus Bindestrichen, eine Gruppe pro Spalte, und zeigt dem Renderer, dass die Zeilen darüber und darunter eine Tabelle bilden.

| Obst   | Preis  | Vorrätig |
| ------ | -----: | :------: |
| Apfel  | 1,20 € |    ja    |
| Birne  | 0,90 € |   nein   |
| Banane | 0,35 € |    ja    |

Die Regeln, auf die es ankommt

Die kürzeste gültige Form funktioniert, ist aber schwerer zu lesen:

Linus | Redaktion
  • Die Kopfzeile ist Pflicht. In GFM gibt es keine Tabellen ohne Kopfzeile.
  • Die Trennzeile muss genau so viele Zellen haben wie die Kopfzeile, sonst wird der Block nicht als Tabelle erkannt.
  • Jede Zelle der Trennzeile braucht mindestens einen Bindestrich. Drei sind üblich und werden überall verstanden.
  • Zeilen mit weniger Zellen werden mit leeren Zellen aufgefüllt, überzählige Zellen fallen weg.
  • Striche am Zeilenanfang und -ende sind optional, machen den Quelltext aber lesbarer. Bei einer einspaltigen Tabelle solltest du sie behalten.
  • Die Spalten müssen im Quelltext nicht bündig stehen. Leerzeichen um den Zelleninhalt werden entfernt.
  • Die Tabelle endet bei der ersten Leerzeile oder wenn ein anderer Block beginnt, etwa eine Überschrift oder Liste. Lass auch vor der Tabelle eine Leerzeile.

Spalten ausrichten

Doppelpunkte in der Trennzeile legen die Ausrichtung einer ganzen Spalte fest, Kopfzelle eingeschlossen. Rechtsbündig ist praktisch für Zahlen, damit die Nachkommastellen untereinanderstehen.

Zelle in der TrennzeileAusrichtung
| --- |Standard (meist links)
| :--- |Links
| :---: |Zentriert
| ---: |Rechts

Formatierung in Zellen

Zellen dürfen Markdown im Text enthalten: fett, kursiv, Code, Links, Bilder und Durchstreichen. Blockelemente gehen nicht – also keine Listen, Überschriften, Codeblöcke oder mehrere Absätze in einer Zelle.

| Befehl       | Beschreibung               |
| ------------ | -------------------------- |
| `git status` | Zeigt **geänderte** Dateien |
| `git log`    | Siehe [Doku](https://git-scm.com/docs) |

Den senkrechten Strich maskieren

Ein | in einer Zelle würde eine neue Spalte beginnen. Schreib stattdessen \|. In GFM gilt das auch für Code innerhalb einer Tabelle: `a \| b` erscheint als a | b in Code-Formatierung.

| Operator | Bedeutung |
| -------- | --------- |
| `a \| b` | a oder b  |
| \|x\|    | Betrag    |

Was Markdown-Tabellen nicht können

Die Syntax ist bewusst einfach. Brauchst du etwas aus der folgenden Liste, musst du auf eine HTML-Tabelle ausweichen – und das nur dort, wo dein Renderer HTML erlaubt:

  • Verbundene Zellen (kein colspan oder rowspan)
  • Mehrere Absätze oder Listen in einer Zelle
  • Tabellenüberschriften (Captions)
  • Feste Spaltenbreiten
  • Tabellen ohne Kopfzeile

Zeilenumbrüche in Zellen

Eine Zelle muss im Quelltext in eine Zeile passen. Viele Renderer, auch GitHub, akzeptieren das HTML-Tag <br> in einer Zelle, um einen Umbruch zu erzwingen. Ob das anderswo klappt, hängt davon ab, ob der Renderer HTML durchlässt.

Tabellen auf dem iPhone und iPad schreiben

Striche und Bindestriche auf der Handytastatur zu tippen, ist fummelig. In Markdown Editor fügt die Formatierungsleiste über der Tastatur eine Tabelle mit einem Tipp ein, und die Vorschau zeigt sie als echte Tabelle. Auf dem iPad siehst du Quelltext und Live-Vorschau nebeneinander, sodass ein fehlender Strich sofort auffällt. Deine Dokumente bleiben normale .md-Dateien in der Dateien-App. Mit Markdown Editor Pro exportierst du sie schön formatiert als PDF oder HTML.

Häufige Fragen

Wie richte ich eine Spalte in einer Markdown-Tabelle aus?

Mit Doppelpunkten in der Trennzeile: :--- für links, :---: für zentriert und ---: für rechts. Die Ausrichtung gilt für die ganze Spalte.

Kann ich in einer Markdown-Tabelle Zellen verbinden?

Nein. Markdown-Tabellen kennen kein colspan oder rowspan. Brauchst du verbundene Zellen, nimm eine HTML-Tabelle in einem Renderer, der HTML erlaubt.

Wie schreibe ich ein | in eine Tabellenzelle?

Maskier es mit einem Backslash: \|. In GitHub Flavored Markdown funktioniert das auch in Code innerhalb der Tabelle.
