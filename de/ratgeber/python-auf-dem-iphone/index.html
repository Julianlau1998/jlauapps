Wie Python auf dem iPhone läuft

Apps können ihren eigenen Python-Interpreter mitbringen. Läuft er direkt auf dem Gerät, braucht dein Code keinen Server und du keine Verbindung, um ihn auszuführen.

So arbeitet Python Editor: Python 3 läuft direkt in der App, auch offline und ohne Konto. print() und input() funktionieren in einer Konsole wie im Terminal, und Fehler kommen mit Zeilennummer und einem verständlichen Hinweis, was schiefgelaufen ist.

Dein erstes Skript mit input()

Interaktive Programme sind der beste Einstieg. Dieses fragt nach deinem Namen und ein paar Punktzahlen und gibt den Durchschnitt aus. Lass die Eingabe leer, um aufzuhören. Die Texte in den Anführungszeichen kannst du gern auf Deutsch ändern.

name = input("Your name: ")
scores = []

while True:
    entry = input("Score (leave empty to finish): ")
    if entry == "":
        break
    scores.append(float(entry))

if scores:
    average = sum(scores) / len(scores)
    print(f"{name}, your average is {average:.1f}")
else:
    print("No scores entered.")
  • input() liefert immer Text, deshalb macht float(entry) daraus eine Zahl.
  • Die Schleife while True läuft, bis break erreicht wird.
  • Der f-String mit :.1f gibt eine Nachkommastelle aus.

Dateien aus deinem Projekt lesen

Echte Programme arbeiten oft mit Daten. Leg neben dein Skript eine Datei data.csv mit der Kopfzeile name,points und danach einer Zeile pro Person, etwa Ada,42. Das Modul csv aus der Standardbibliothek liest sie als Dictionaries ein.

import csv

with open("data.csv", newline="") as f:
    rows = list(csv.DictReader(f))

for row in rows:
    print(row["name"], row["points"])

best = max(rows, key=lambda row: int(row["points"]))
print("Top score:", best["name"])
  • In Python Editor ist jeder Ordner ein Projekt mit Dateiliste und Tabs.
  • Dein Programm liest Dateien wie data.csv aus seinem Ordner und kann eigene Module importieren.
  • Ordner aus der Dateien-App und iCloud Drive öffnest du direkt dort, wo sie liegen.

Welche Bibliotheken dabei sind

Die gesamte Standardbibliothek ist da: math, random, csv, json, datetime, collections, re und der Rest. Darüber hinaus bringt Python Editor numpy und matplotlib mit, sodass du offline mit Arrays rechnen und Diagramme zeichnen kannst. Weitere Pakete wie pandas, scipy oder sympy lädt die App beim ersten import – dieses eine Mal brauchst du Internet.

Nicht jedes Paket aus PyPI funktioniert auf dem Handy. Bibliotheken, die ein Desktop-Fenster, Hardwarezugriff oder einen laufenden Server brauchen, kommen meist nicht infrage.

numpy und matplotlib auf dem iPad

Dieses Skript berechnet Sinus und Kosinus für 200 Punkte und zeichnet beide Kurven. In Python Editor erscheint das Diagramm direkt in der Konsole.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 200)
plt.plot(x, np.sin(x), label="sin(x)")
plt.plot(x, np.cos(x), label="cos(x)")
plt.legend()
plt.title("Sine and cosine")
plt.show()

Fehlermeldungen verstehen

Läuft etwas schief, gibt Python einen Traceback aus. Lies ihn von unten: Die letzte Zeile nennt den Fehlertyp und was passiert ist, die Zeilen darüber zeigen, wo. Diese begegnen dir am Anfang am häufigsten:

FehlerBedeutet meist
SyntaxErrorEin fehlender Doppelpunkt, eine Klammer oder ein Anführungszeichen
IndentationErrorZeilen in einem Block sind nicht einheitlich eingerückt
NameErrorTippfehler in einem Namen, oder eine Variable wird benutzt, bevor sie gesetzt ist
ValueErrorZum Beispiel float("abc") – Text, der keine Zahl ist
FileNotFoundErrorDie Datei liegt nicht in dem Ordner, in dem du sie vermutest

Tipps für Python auf dem Touchscreen

Einrückung gehört bei Python zur Syntax – deshalb ist ein guter Editor auf dem Handy so wichtig. Python Editor rückt nach einem Doppelpunkt automatisch ein, schließt Klammern und Anführungszeichen und hat eine Leiste über der Tastatur mit Tab, Sonderzeichen und Bausteinen wie if, for, def und class. Mit einer Hardware-Tastatur am iPad funktionieren auch Tastaturkurzbefehle.

Python Editor bringt 20 Beispiele zum Start mit – darunter Zahlenraten, Schere-Stein-Papier, Primzahlen und ein Quiz aus JSON –, und jedes wird eine eigene Datei, die du verändern kannst. Häufige Fragen

Kann ich Python auf dem iPhone ohne Internet ausführen?

Ja. Python Editor führt Python 3 direkt auf dem Gerät aus, samt Standardbibliothek, numpy und matplotlib. Nur zusätzliche Pakete wie pandas brauchen einmal eine Verbindung, wenn sie beim ersten import geladen werden.

Kann ich pandas auf dem iPad nutzen?

In Python Editor wird pandas geladen, wenn dein Programm es zum ersten Mal importiert. Danach nutzt du es wie auf einem Computer.

Funktioniert input() auf dem iPhone?

Ja. In Python Editor fragt input() deine Antwort in der Konsole ab, genau wie in einem Terminal am Computer.
