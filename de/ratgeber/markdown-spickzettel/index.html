Codeblöcke

Für mehrzeiligen Code setzt du drei Backticks in eine eigene Zeile vor und nach dem Code. Das Wort nach den öffnenden Backticks gibt die Sprache an; viele Renderer nutzen es für Syntax-Highlighting. Drei Tilden (~~~) funktionieren genauso.

Verschachtelte Listen und Checklisten

Ein Unterpunkt muss so weit eingerückt sein, wie der Text des übergeordneten Punkts beginnt: zwei Leerzeichen unter - Punkt, drei unter 1. Punkt. Die Zahlen einer nummerierten Liste müssen nicht fortlaufend sein; der Renderer zählt ab der ersten Zahl weiter.

Typische Stolperfallen

  • --- direkt unter einer Textzeile macht diese Zeile zur Überschrift. Lass über einer Trennlinie eine Leerzeile.
  • Ein einfacher Zeilenumbruch im Absatz wird als Leerzeichen dargestellt. Beende die Zeile mit zwei Leerzeichen oder einem Backslash – oder beginne mit einer Leerzeile einen neuen Absatz.
  • Lass zwischen Blöcken wie Absätzen, Listen, Tabellen und Codeblöcken eine Leerzeile. Das ist immer gültig und vermeidet Überraschungen in strengeren Renderern.
  • HTML ist in CommonMark erlaubt, wird aber von vielen Apps und Websites aus Sicherheitsgründen gefiltert.
  • Ein wörtliches *, _, # oder [ bekommst du mit einem Backslash davor.

Häufige Fragen

Wie schreibe ich in Markdown fett und kursiv?

Mit **fett** für fett, *kursiv* für kursiv und ***Text*** für beides. Unterstriche (__fett__, _kursiv_) gehen auch, aber nicht mitten im Wort.

Was ist der Unterschied zwischen CommonMark und GitHub Flavored Markdown?

CommonMark ist eine genaue Spezifikation der Markdown-Grundsyntax. GitHub Flavored Markdown baut darauf auf und ergänzt Tabellen, Checklisten, Durchstreichen und automatische Links für nackte URLs.

Wie mache ich einen Zeilenumbruch ohne neuen Absatz?

Beende die Zeile mit zwei Leerzeichen oder einem Backslash. Ein einfacher Zeilenumbruch wird als Leerzeichen dargestellt, eine Leerzeile beginnt einen neuen Absatz.
