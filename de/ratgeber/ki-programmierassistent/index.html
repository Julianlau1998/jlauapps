Programmieren mit KI-Assistent auf dem iPad

KI-Modelle wie Claude, ChatGPT und Gemini sind nützliche Partner beim Programmieren geworden. Sie erklären Fehler, schreiben erste Entwürfe und schlagen Lösungen vor – und auf dem iPad, wo lange Codeblöcke mühsam zu tippen sind, ist diese Hilfe besonders viel wert.

Ein Assistent ist aber nur so gut wie die Art, wie du ihn nutzt. In dieser Anleitung geht es darum, wie du gute Fragen stellst, wie du prüfst, was die KI ändert, was ein API-Schlüssel ist und worauf du beim Datenschutz achten solltest.

Chatfenster oder Assistent im Editor

Es gibt zwei Wege, auf dem iPad mit KI zu programmieren. Du kannst Code in eine Chat-App kopieren und die Antwort zurück einfügen. Das funktioniert, ist aber umständlich, und die KI sieht nur, was du einfügst – nicht deine übrigen Dateien.

Der andere Weg ist ein Assistent direkt im Editor. In Code Editor (Pro) fragst du Claude, ChatGPT oder Gemini direkt neben deinem Code. Der Assistent liest die Dateien deines Projekts und schlägt Änderungen vor, und deine Unterhaltung wird pro Projekt gemerkt.

So schreibst du einen guten Prompt

Vage Bitten bringen vage Ergebnisse. Ein guter Prompt sagt, was du willst, wo, und woran du merkst, dass es klappt.

  • Sei konkret: „Gib style.css einen Dark Mode, der der Systemeinstellung folgt“ ist besser als „mach es schöner“.
  • Beschreib das Symptom: „Der Button auf index.html tut beim Antippen nichts, und die Konsole zeigt keinen Fehler.“
  • Füge die genaue Fehlermeldung samt Zeilennummer ein.
  • Bitte um eine Änderung nach der anderen – kleine Schritte lassen sich leichter prüfen.
  • Bitte zusätzlich um eine Erklärung, wenn du etwas lernen und nicht nur reparieren willst.

Jede Änderung prüfen

KI-Modelle schreiben Code, der plausibel aussieht, und meistens stimmt er auch. Sie können aber deine Absicht missverstehen, Funktionen erfinden, die es nicht gibt, oder still etwas entfernen, das du gebraucht hast. Behandle vorgeschlagenen Code wie den Beitrag eines Kollegen: Lies ihn, bevor du ihn übernimmst.

Code Editor zeigt jede vorgeschlagene Änderung farbig markiert, und du entscheidest selbst, ob du sie übernimmst. Frühere Stände bleiben im Versionsverlauf, sodass du zurückkannst, wenn sich eine Änderung als falsch herausstellt.

  • Lies die markierte Änderung und prüfe, ob sie nur das betrifft, worum du gebeten hast.
  • Teste das Ergebnis sofort in der Live-Vorschau oder der Konsole.
  • Verstehst du eine Zeile nicht, lass sie dir erklären, bevor du sie behältst.

API-Schlüssel: was sie sind und was sie kosten

Apps sprechen über eine API mit KI-Modellen, und der Anbieter erkennt dich an einem API-Schlüssel – einer langen, geheimen Zeichenfolge, die du in deinem Konto bei Anthropic (Claude), OpenAI (ChatGPT) oder Google (Gemini) erstellst. Abgerechnet wird pro Anfrage beim jeweiligen Anbieter.

Code Editor funktioniert mit deinem eigenen API-Schlüssel von einem dieser drei Anbieter; Anfragen an den Assistenten rechnet der Anbieter über diesen Schlüssel ab. Chat-Abos wie ChatGPT Plus oder Claude Pro sind übrigens eigene Produkte und enthalten keine API-Nutzung.

  • Behandle einen API-Schlüssel wie ein Passwort: nicht in Code-Dateien einfügen und nicht auf Screenshots zeigen.
  • Setz in deinem Anbieterkonto ein Ausgabenlimit, wenn es das anbietet.
  • Gerät ein Schlüssel in falsche Hände, lösch ihn im Dashboard des Anbieters und erstell einen neuen.

Datenschutz: Was die KI sieht

Liest ein Assistent deine Dateien, wird ihr Inhalt an den gewählten KI-Anbieter geschickt, damit das Modell antworten kann. So funktionieren diese Dienste, unabhängig von der App. Überleg dir deshalb, was in einem Projekt steckt, bevor du KI darauf ansetzt.

  • Bewahre keine Passwörter, Tokens oder API-Schlüssel in Projektdateien auf.
  • Sei vorsichtig mit personenbezogenen Daten wie Kundenlisten oder exportierten Nutzerdaten.
  • Prüfe die Datenschutzregeln deines Anbieters, besonders bei Projekten für Arbeit oder Schule.
  • Bei sensiblem Code lass den Assistenten weg – der Editor funktioniert auch ohne ihn.

Lernen mit KI-Assistent

Wenn du programmieren lernst, kann ein Assistent ein geduldiger Nachhilfelehrer sein – oder eine Abkürzung, die dich am Lernen hindert. Lass dir Fehler erklären, statt sie nur beheben zu lassen, versuch eine Aufgabe zuerst selbst und vergleich deine Lösung danach mit dem Vorschlag.

Häufige Fragen

Welche KI ist am besten zum Programmieren: Claude, ChatGPT oder Gemini?

Alle drei kommen gut mit HTML, CSS, JavaScript und Python zurecht, und die Modelle ändern sich oft. Probier dieselbe Aufgabe mit jedem aus und bleib bei dem, dessen Antworten du am klarsten findest. In Code Editor kannst du alle drei nutzen.

Brauche ich ein Abo wie ChatGPT Plus oder Claude Pro?

Nein. Code Editor nutzt einen API-Schlüssel von Anthropic, OpenAI oder Google, der pro Anfrage über das Entwicklerkonto des Anbieters abgerechnet wird. Chat-Abos können andere Apps nicht nutzen.

Ist der KI-Assistent in Code Editor kostenlos?

Der Assistent gehört zu Code Editor Pro. Zusätzlich rechnet dein KI-Anbieter die Anfragen über deinen eigenen API-Schlüssel ab.
